# Rock-Paper-Scissors Game 🎮✊✋✌️

A **fun and interactive Rock-Paper-Scissors game** built with **HTML, CSS, and JavaScript**. Play against the computer and see if you can beat it!  

## Features

- ✅ **Play against the computer** with random choices  
- ✅ **Interactive messages** with emojis for Win 🎉, Lose 😢, and Draw 🤝  
- ✅ **Scoreboard** updates dynamically for both player and computer  
- ✅ **Reset button** to start a new game anytime  
- ✅ **Winning choice glow effect** for visual feedback  
- ✅ Fully **responsive layout** for desktops and tablets  
- ✅ Attractive **heading and UI** with gradients, shadows, and animations  

## How to Play

1. Click on **Rock, Paper, or Scissors**  
2. See the computer’s choice and the result (Win/Lose/Draw)  
3. Watch your score update in real-time  
4. Press **Reset Game** to start over  

---

## Tech Stack

- **HTML5** – Structure of the game  
- **CSS3** – Styling, gradients, hover effects, and animations  
- **JavaScript (ES6)** – Game logic, DOM manipulation, event handling
